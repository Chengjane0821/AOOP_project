Milestone: deterministic scoring model. First to five rally points wins each game; first to two games wins match. No deuce. Threshold sampled uniformly 20..30 each game. Both accepted paddle contacts count. Rally hits reset on serve; cumulative game hits allow the target across rallies. Two valid player smashes accumulate within game. Earned failure makes Elder deliberately miss; game victory occurs only when that ball faults. Lost match resets score to 0-0 before retry.

Milestone: controller paddle samples tracked device pose in the XRI camera-offset coordinate system. Both hands supported; Grip is read from XR input. Desktop mouse moves paddle, F advances it, Space holds simulated Grip. Hits require actual movement/contact.
Milestone: physics uses a 40 mm / 2.7 g continuous rigidbody, kinematic paddle bodies, relative swept paddle contact tests, per-contact cooldown and alternating return ownership. Table uses a physical bounce material. Hits apply momentum impulses with capped ball speed and configurable aim assistance. The default project timestep is retained.
Milestone: NPC predicts incoming ball position, has bounded paddle speed, reaction delay and small shot-specific error. Upon the game hit target or second successful smash, it moves its paddle aside; no score is awarded until a subsequent physical fault.
Milestone: match coordinator handles countdowns, first-to-five games, best-of-three, point/game feedback, menu/tracking pause, restart, and lost-match reset. Photo is unavailable until victory AND the memory dialogue acknowledgment. Clue ID 0 is awarded only by photo interaction.

FINAL FEATURE NOTES
Story: the Elder remembers little about last night, but remembers loving table tennis. Let's play starts the match; Maybe later safely closes the conversation. The resident can be approached again. The recovered memory describes a missing table-tennis partner who asked about memories and strange experiments, and an old photograph with a scratched-out face.
Reward: winning two games saves the victory but does not award a clue. Acknowledging the memory enables the original photograph. Inspecting it awards Clue #1 (index 0), inventory and journal entries and house completion. Replays never erase an earned clue. All five clues remain necessary for the Abandoned House; the other four camera quests and final ending remain intact.
VR: active right/left controller poses are transformed through the existing XRI camera-offset space. Translational and wrist angular velocity contribute to contact. Both paddle faces work. Grip never counts without a valid moving collision. Normal responses use capped physical impulses with configurable assistance; valid smashes use a directed ballistic impulse. Tracking loss and menus pause the rally. Activity locomotion is restored on leave, loss, victory and scene unload.
Smash: player-side reachable ball; configurable height range, descending/near-apex trajectory, swing-speed and forward-speed thresholds, and face alignment. Bad moving Grip contact produces MISS and an Elder point. Accepted contacts count once through cooldown/ownership/phase guards. Smash thresholds are exposed in TableTennisTuning.asset. Defaults still need actual controller calibration.
NPC: bounded speed and reaction delay, incoming trajectory prediction including table bounce, small shot-specific error. On the 20–30 cumulative game-hit target or second valid smash, paddle moves aside. Game win follows the actual missed-return outcome. Counters and target regenerate for the next game; lost best-of-three resets progress completely before retry.
Presentation: table/net, actual ball trail, two paddles, original Elder, standing markers, readable scoreboard and instruction panels, countdown, hit/bounce audio, controller haptics, SMASH/MISS/game/match messages, pause/restart and replay. Existing furniture retains authored scale. Model audit verified tabletop near 0.76 m, net 0.1525 m above it, ball 40 mm and paddle face approximately 17 x 18 cm aligned with the collision face.
